# README posters

These PNGs are the GitHub-facing copies of the Zorost LLM roadmaps.
HTML sources and extra diagrams live in [`../assets/diagrams/`](../assets/diagrams/).

| File | Use |
|---|---|
| `banner.png` | Top of the repository README |
| `social.png` | Link-preview card |
| `roadmap_fundamentals.png` | Track 0 |
| `roadmap_scientist.png` | Track 1 |
| `roadmap_engineer.png` | Track 2 |
| `roadmap_operator.png` | Track 3 |
| `roadmap_leader.png` | Track 4 |

Original artwork. Rebuild with `python3 scripts/build_roadmaps.py` then
`python3 scripts/export_diagrams.py`. See [`../docs/ROADMAPS.md`](../docs/ROADMAPS.md).
