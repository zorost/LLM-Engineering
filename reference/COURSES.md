# Courses we point at (and do not copy)

Independent programs. Take them when the module says to. We do not
reproduce their text, notebooks, or certificates. Completion of
those certificates is not completion of this repository.

Zorost Intelligence is not affiliated with Hugging Face,
DeepLearning.AI, Stanford, fast.ai, Manning, O'Reilly, or Maxime
Labonne, except as a public reader and citer.

## DeepLearning.AI (pointers, not a mirror)

Short courses on [learn.deeplearning.ai](https://learn.deeplearning.ai/)
change names. Use the catalog. The ones this course respects as
**practice after the idea**:

- Prompt engineering for developers (and the "building systems
  with the ChatGPT API" follow-on): after E1, not instead of
  evals.
- RAG / vector-database / "chat with your data" family: after
  labs 08 and 09, so you already know hybrid search without a
  vendor SDK.
- Agentic design-pattern courses: after lab 10.

Andrew Ng's **AI Engineering Skills Map** is a letter, not a
course: [The Batch](https://www.deeplearning.ai/the-batch/the-ai-engineering-skills-map)
and [issue 366](https://www.deeplearning.ai/the-batch/issue-366)
(August 2026). Required for L2. Independent. Not a Zorost product.

## Labonne llm-course (hub, not a source text)

[github.com/mlabonne/llm-course](https://github.com/mlabonne/llm-course)
is a widely used public **roadmap hub**: three tracks, dense
pointers, Colab links. We read it end to end when we designed this
repository ([docs/ASSESSMENT.md](../docs/ASSESSMENT.md)). We kept
the coverage skeleton. We rewrote every explanation. We do not
fork it. We do not copy its artwork, README wording, or notebooks.
If you want a bookmark list of yet more blogs, use that hub. If
you want modules you can fail, stay here.
