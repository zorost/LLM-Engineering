## The AI Leadership Textbook

**Hashemipour, Fereydun.** *The AI Leadership Textbook: From Silicon
to the Boardroom: The Complete Field Guide for Executives,
Architects, and Engineers.* First edition. Independently published,
2026.

| Format | Identifier | Link |
|---|---|---|
| Kindle | ASIN **B0HHTJHK5R** | [amazon.com/dp/B0HHTJHK5R](https://www.amazon.com/dp/B0HHTJHK5R) |
| Paperback | ISBN **979-8-1718-2328-3** (979-8171823283) | Search the ISBN on Amazon |
| Hardcover | ISBN **979-8-1719-7165-6** (979-8171971656) | Search the ISBN on Amazon |

**What it is.** A field guide from silicon to the boardroom: 44
chapters covering platforms, operating models, governance, talent,
and playbooks. The Leader track (L1 to L4) assumes you will read
the matching chapters rather than treat these modules as a
substitute.

**How this course uses it.** L1 (buy versus build), L2 (operating
model and talent), L3 (governance), L4 (portfolio). Study plan C
in [docs/STUDY-PLANS.md](../docs/STUDY-PLANS.md).

**Bibliographic note.** Publisher on the Amazon print listing:
Independently published. Author as on Author Central: Fereydun
Hashemipour.

## AI Engineering Distilled

**Hashemipour, Fereydun.** *AI Engineering Distilled: The Systems
Design Guideline for Software Engineers and Web Developers.* First
edition. Independently published, 2026.

| Format | Identifier | Link |
|---|---|---|
| Kindle | ASIN **B0HHZM4QQS** | [amazon.com/dp/B0HHZM4QQS](https://www.amazon.com/dp/B0HHZM4QQS) |
| Paperback | ISBN **979-8-1723-3326-2** (979-8172333262) | Search the ISBN on Amazon |
| Hardcover | ISBN **979-8-1723-3787-1** (979-8172337871) | Search the ISBN on Amazon |

**What it is.** A short design book: Seam notation (sixteen
elements, five views: Boundary, Context, Run, Evidence,
Configuration), twelve principles, and a bounded pattern catalog
(context, control, trust, evidence). It is not a coding book and
not a model zoo.

**How this course uses it.** L1 (Boundary and Context), L2
(concept phase / shaping), L3 (Evidence view), L4 (Trust family
and Configuration record). Engineer readers who specify agents
and RAG should steal the seam vocabulary even if they skip the
Leader track.

**Bibliographic note.** Same author page as above. Independently
published.

### Chip Huyen, *AI Engineering*

**Huyen, Chip.** *AI Engineering: Building Applications with
Foundation Models.* Sebastopol, CA: O'Reilly Media, 2025.

- Print ISBN-13: **978-1-098-16630-4** (10: 1098166302)
- O'Reilly Safari / ebook ISBN-13: **978-1-098-16629-8**
- Catalog: [oreilly.com/library/view/ai-engineering/9781098166298](https://www.oreilly.com/library/view/ai-engineering/9781098166298/)

**Use it for.** The Engineer track's application loop: evals,
RAG, inference, feedback. Pair with E3, E6, E10, O3. Does not
replace the Operator or Leader tracks.

### Sebastian Raschka, *Build a Large Language Model (From Scratch)*

**Raschka, Sebastian.** *Build a Large Language Model (From
Scratch).* Shelter Island, NY: Manning Publications, 2024.

- ISBN-13: **978-1-63343-716-6** (10: 1633437167)
- Site: [manning.com](https://www.manning.com/) (search the title)

**Use it for.** Scientist readers who want to type a GPT-class
model, training loop, and a first instruction tune. Pair with S1,
S2, S4. Complements CS336; does not replace it.

### Iusztin and Labonne, *LLM Engineer's Handbook*

**Iusztin, Paul, and Maxime Labonne.** *LLM Engineer's Handbook:
Master the art of engineering large language models from
architecture to production.* Birmingham: Packt Publishing, 2024.

- ISBN-13: **978-1-83620-007-9** (10: 1836200072)

**Use it for.** An additional practitioner handbook on pipelines
and tooling. Related third-party, not a Zorost text. Labonne's
[llm-course](https://github.com/mlabonne/llm-course) remains a
hub we do not copy ([COURSES.md](COURSES.md),
[docs/ASSESSMENT.md](../docs/ASSESSMENT.md)).
