# Tutorials

These notes sit between a track module and a notebook. The module
explains the idea. The notebook makes you break it. The tutorial
says how the lab is supposed to **feel** when it is working, and
what it means when it is not.

Read the matching tutorial before the lab if the module felt
abstract. Skip it if you already finished the lab and can answer
the knowledge check with the answers hidden.
